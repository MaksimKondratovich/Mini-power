# PCB

100 x 100 mm, 2 layers, generated by scripts (see "Rebuild"). DRC with schematic parity: **0 violations, 0 unconnected, 0 parity issues** (`kicad-cli pcb drc --schematic-parity`).

## Two clearly separated sections
| | STANDALONE (left, x 0 to 50 mm) | CONTROLLER-DRIVEN (right, x 50 to 100 mm) |
|---|---|---|
| Supply | +3.3 V, header **J1** | separate +2.75 V, header **J3** |
| Blocks | A +2.8 V (U1), B +1.4 V (U2), C -2.8 V (U3 LT8330) | D +1.375 V, E-A charge pump, E-B P-FET stage with sense amplifier (U4) |
| Outputs | **J2** (GND, +2.8 V, -2.8 V, +1.4 V) and series jumpers JP1 to JP3 | **J4** (GND, +1.375 V, -2.75 V), series jumpers JP4, JP5 (A), JP6 (B) |
| Controller | none | STM32 on **J5** (6-pin interface) |

- A 0.4 mm silkscreen line at x = 50 mm divides the board, with a titled half on each side and block letters (A to C, D, E-A, E-B).
- **No signal track and no via crosses the divider.** The only thing the two halves share is the GND plane (the bottom layer).
- Every net has exactly one test point (29 bare 0.5 mm copper dots with a solder-mask opening; test point names are on the F.Fab layer to keep the silkscreen readable).

## Rules used (JLCPCB standard 2-layer)
- Clearance 0.10 mm, tracks 0.15 mm (all nets: currents are a few mA), vias 0.5 / 0.3 mm, copper to edge 0.3 mm.
- Bottom layer: solid GND pour (thermal reliefs on header pins). SMD GND pads reach it through short stubs and vias; 14 other vias carry signals across the pour.
- Footprints come from easyeda2kicad (`mini-power/lib/mp.pretty`); the pin-1 dots were moved from the silkscreen to the fab layer so the silkscreen does not sit on pads.

## Things to know
- The router is my own small grid router (`tools/pcb_route.py`): orthogonal tracks only, no length matching, no shielding. Switching loops are not optimised: the standalone blocks have 5 to 10 mm between the IC, inductor and capacitors, longer than a hand layout would be. For the LT8330 and TPS62840 rails, check the efficiency and noise on the bench before drawing conclusions about the circuit.
- The two high-impedance nodes of the sense amplifier (SNS_IN, 5 Mohm) run a few mm on the top layer over the GND plane; keep the board clean.
- Not done yet: Gerbers, drill files, BOM/CPL for JLCPCB, 3D check. Manual part checks against JLCPCB stock are still needed.

## Rebuild
Close KiCad first. From the repository root:
```
kicad-cli sch export netlist --format kicadsexpr -o out/net.net mini-power/mini-power.kicad_sch
"C:/Program Files/KiCad/9.0/bin/python.exe" tools/pcb_place.py     # footprints, nets, test points
"C:/Program Files/KiCad/9.0/bin/python.exe" tools/pcb_route.py     # routes to out/pcb_routes.json (about a minute)
"C:/Program Files/KiCad/9.0/bin/python.exe" tools/pcb_finish.py    # tracks, vias, GND pour, silkscreen
kicad-cli pcb drc --schematic-parity --severity-all -o out/drc.rpt mini-power/mini-power.kicad_pcb
py -3.12 tools/render_pcb.py                                     # PNG previews in out/
```
Placement coordinates are in the `PLACE` table in `tools/pcb_place.py`.
