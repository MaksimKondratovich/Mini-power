# Mini-power (KiCad 9 project)

- Project files live in `mini-power/` (`.kicad_pro`, `.kicad_sch`, `.kicad_pcb`).
- `kicad-cli` is installed but not on PATH. Use the full path:
  `C:\Program Files\KiCad\9.0\bin\kicad-cli.exe` (v9.0.9).
- Common commands (run from repo root; write outputs to `out/`, which is untracked):
  - ERC: `kicad-cli sch erc -o out/erc.rpt mini-power/mini-power.kicad_sch`
  - DRC: `kicad-cli pcb drc -o out/drc.rpt mini-power/mini-power.kicad_pcb`
  - Schematic PDF: `kicad-cli sch export pdf -o out/sch.pdf mini-power/mini-power.kicad_sch`
  - BOM: `kicad-cli sch export bom -o out/bom.csv mini-power/mini-power.kicad_sch`
  - Gerbers: `kicad-cli pcb export gerbers -o out/gerbers/ mini-power/mini-power.kicad_pcb`
- Close the project in KiCad before editing files by hand, or KiCad may overwrite the edits.

## Parts policy
- Use only **LCSC parts available in the JLCPCB library**. "Regular" = JLCPCB basic parts, but the user **allows extended parts** (the basic library has no suitable converter ICs). Prefer basic parts for passives where a suitable one exists. Check the LCSC part number (Cxxxxx) and stock before adding any component; see the JLCPCB parts API trick in memory.
- Import parts with easyeda2kicad (v1.0.1). It lives in Python 3.12, not the default 3.14, so run it as:
  `py -3.12 -m easyeda2kicad --full --lcsc_id Cxxxxx --output <lib path> [--project-relative]`
  (`--symbol`, `--footprint`, `--3d` import them individually.)
- Keep the LCSC number in each symbol's fields so BOM exports carry it.

## Way of working
- **Documentation with every component selection:** write up how the circuit works and why each specific value/IC was chosen. Include all calculations. Keep docs in `docs/` (one markdown file per circuit block).
- **Analysis depth:** nominal values only. No complex thermal or tolerance analysis.
- **Passives:** resistors must be 1% or better (no 5% parts). Do not use class 3 capacitors.
- **Test points:** every net gets exactly one test point: a bare copper dot, 0.5 mm diameter, without solder mask (mask opening over the pad). Nothing else.

## System constraints
- PCB maximum size: 100 x 100 mm.

## Schematic style
- Schematics must be drawn in a human-readable way.

## Requirements
See `docs/requirements.md` (3.3 V in; +2.75 V, -2.75 V, +1.375 V out; 5 mA max each, 1 mA typical, no accuracy/ripple/noise limits, common ground; efficiency is the top priority; series jumper header per output rail).

## Schematic generation
- `mini-power/mini-power.kicad_sch` is generated by `python tools/gen_schematic.py` (symbols come from `mini-power/lib/`). Edit the script and regenerate; hand edits in KiCad will be overwritten on the next run.
- Libraries: `mini-power/lib/mp.*` (imported LCSC parts), `mini-power/lib/mpx.kicad_sym` (GND, PWR_FLAG, TestPoint), footprint `mp:TestPoint_0.5mm`.
- Check with: `kicad-cli sch erc -o out/erc.rpt mini-power/mini-power.kicad_sch`.

## Controller-driven rails (drawn on the right of the sheet, paper A2)
See `docs/controller-rails.md` and `tools/controller_rails_model.py`. A separate +2.75 V input (J3) powers the abstract low-power STM32 (header J5) and the pin-driven stages; outputs +1.375 V and -2.75 V (separate series jumpers JP5 = charge pump A and JP6 = inductor stage B, fit only one) on J4.
